# Example recipes — v4

All JSON files use the public validators. Run `npm run examples` to regenerate them and `npm run test:examples` to check them.

The folder has 65 JSON files: 37 model blueprints, nine mixer recipes, nine mixed-result blueprints, two kit-result blueprints, six actor manifests, and two rosters. Each mixer recipe includes both source snapshots. Nothing in these files is an executable hook.

Start with `duelist.morph.json`, `grovekeeper.morph.json`, or `crownstag.morph.json`. `guard-kit.morph.json` is Wayfarer with the Guard kit. `botanical-kit.morph.json` shows a kit on a one-node creature. `travel-party.roster.json` contains six seeded Outrider variants.

Import files through the editor's normal Import control. A roster populates the Actor panel. A mixer recipe populates the Mixer. One actor is previewed at a time. These files contain procedural recipes, not baked meshes or animation clips.
