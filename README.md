# Morph Lab

A procedural monster creator. Roll, vary, and mix creatures from a library of 89 models and 73 part families, inspect them on the CPU, play with them in a physics habitat, and export them as GLB assets. Every model, texture, and motion is generated by code; there are no image, model, or animation files.

## Open the app

Open **`dist/Morph-Lab.html`** in a browser. It is a single self-contained file with three workspaces, switched from its header:

| Workspace | What it's for | Works offline |
|---|---|---|
| **Create** (start screen) | Randomize, vary, lock traits, save discoveries, mix two parents | Yes |
| **Inspect** | CPU geometry inspection, poses, audits, reference comparison, GLB export | Yes |
| **Advanced workshop** | Part-level editing and a Rapier physics habitat (WebGL2) | Needs the engines |

Add `?review` or `?workshop` to the URL to start in Inspect or the Workshop.

The committed file is the CDN edition: the optional GPU preview and the Workshop download Three.js r181 and Rapier compat 0.19.3 from jsDelivr. Everything else works offline. `npm run build:offline` makes a larger file with both engines embedded.

## Create in brief

1. **Randomize monster**, **Vary current**, or **6 variations**.
2. **Save discovery** keeps an immutable copy. Load it later to branch from it.
3. Set two saved discoveries as mixer parents with **A** and **B**, adjust the blend, then **Keep mix** or **Cancel**.

Locks hold traits fixed during rolls and mixes. There are six channels: Body, Head parts, Other parts, Surface, Colors, and Motion. The collection holds up to 48 discoveries in browser storage. Export a backup before you move the file or switch browsers. A seed alone does not reproduce a creature; export the roll/mix recipe or the blueprint. See [docs/creator.md](docs/creator.md).

## Develop

Requires Node.js 22 or later.

```sh
npm install
npm run dev
```

Open <http://localhost:3000/> for Create, `/?review=1` for Inspect, or `/?workshop=1` for the Workshop. The dev server serves `src/` directly as ES modules and uses the engines from `node_modules`. There is no bundler: `npm run build` packs every module into the single HTML file with an import map (`scripts/build.mjs`).

| Command | Does |
|---|---|
| `npm run dev` | Dev server on port 3000 |
| `npm run build` | Writes `dist/Morph-Lab.html` (CDN edition, committed) and `dist/runtime.html` (test artifact) |
| `npm run build:offline` | Same, with the engines embedded |
| `npm test` | Unit tests |
| `npm run check` | Lint, unit, engine, example, geometry-regression, and catalog checks |
| `npm run test:ui` | Build, then every browser suite (Python Playwright) |
| `npm run examples` | Regenerate `examples/` |
| `npm run review:catalog` | Audit and render every model to `test-results/review/` |
| `npm run export:asset -- --preset goblin --out /tmp/goblin` | Export a GLB and asset package from the command line |
| `npm run doctor` | Check that the installed engines match the pinned versions |
| `npm run format` | Prettier and ruff |

[docs/testing.md](docs/testing.md) describes every test command and its requirements. Rebuild and commit `dist/Morph-Lab.html` when you change anything under `src/`, `index.html`, or the CSS.

## Repository layout

```
dist/Morph-Lab.html   the release (generated, committed)
index.html, *.css     the application document and styles
src/
  boot.js, main.js    entry point and the Workshop
  core/               blueprints, anatomy, catalogs, shared geometry, motion, mixing (no DOM)
  creator/            Create workspace
  review/             Inspect workspace and the CPU renderer
  creature/           Three.js parts, materials, and animation for the Workshop
  editor/, ui/        Workshop editor and panels
  export/             GLB, ZIP, and delivery packaging
  physics/, game/     Rapier world and habitat
  render/, diagnostics/
scripts/              build, dev server, review, export, and example tooling
tests/                Node unit tests, engine tests (tests/engine/), Python browser suites
examples/             generated sample blueprints, mixes, actors, rosters, and review sessions
docs/                 guides
```

## Limits

Mixing blends recipes, not arbitrary mesh topology. Different body graphs and rig families switch between sources instead of blending. A few known geometry warnings remain (the abyss angler's arm crown in all sampled phases). Saved discoveries live in the browser, not in an account. Undo/redo covers the current Create session only. The CPU inspector is not the GPU material renderer, and automated tests don't prove GPU appearance or physics behavior on your machine. Use **System checks** in the app for that.
