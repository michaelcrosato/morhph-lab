# Content catalog

Everything in the library is a procedural recipe: models, part geometry, textures and motion are generated by code. There are no imported meshes, texture images or animation clips. Models are stylized sources, not anatomically exact animals or production-approved assets.

Use the IDs below with `--preset` in the [export CLI](export.md#command-line) and with `preset(id)` in code.
