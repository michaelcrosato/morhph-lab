# Create

Create is the start screen of `dist/Morph-Lab.html`. Use it to roll random monsters, vary them, keep the ones you like, and mix two saved discoveries. Inspect and Advanced workshop are in the same file: use the header buttons, or add `?review` or `?workshop` to the URL.

All models, textures and motion are generated by code. Create works offline.

## Open

- Release: open `dist/Morph-Lab.html`. It starts in Create.
- Source: run `npm install` and `npm run dev`, then open `http://localhost:3000/`. The source `index.html` must be served; do not open it from disk.

The preview first draws the actual model geometry with a CPU renderer. When the browser provides WebGL2 and Three.js r181 loads, it switches to a GPU view that uses the Workshop's assembly and materials. Rapier is not needed to create, save or export a creature. A failed engine load or a lost graphics context returns to the CPU preview; **Try WebGL2** retries.

## Explore

| Control | Result |
|---|---|
| **Randomize monster** | Picks a source from the **Source pool** and changes its dimensions, part variants, surface, palette and motion settings. |
| **Vary current** | Starts from the visible creature and blends in a limited amount of a compatible source. **Variation amount** sets the distance from the parent; zero leaves it unchanged. The parent's rig family and travel medium are kept. |
| **6 variations** | Makes six candidates from one fixed parent. Candidates are not derived from each other. Nothing changes until you select one, which is one history step. Save it to keep that branch. |

Source pools: All creatures, Land creatures, Swimmers, Fliers, Humanoids, Everything.

Every change has Undo and Redo, up to 40 recent steps. Undo during a mix preview cancels the preview only. History is lost on a workspace switch or a page reload. The current model, the collection, the parent snapshots and the settings survive a workspace switch.

## Seeds

Turn off **New seed on each roll** to repeat an operation, and enter a whole number from 0 to 4294967295 in **Roll seed**. The same operation, source snapshots, seed, amount and locks give the same result. A seed alone cannot reproduce a descendant of a saved creature; export a recipe for that.

## Traits and locks

| Trait | Scope |
|---|---|
| Body | Body dimensions and rig proportions, including the head shape |
| Head parts | Head-mounted and face/eye attachments |
| Other parts | All other appendage and equipment genes |
| Surface | Pattern layers, roughness, microtexture recipe, relief and emission |
| Colors | Base and accent pigment |
| Motion | The procedural motion recipe and its settings |

A single-trait roll holds the other channels and keeps the global geometry seed. A Body roll keeps the existing attachments; their mounts follow the changed body. It never adds or removes body nodes.

A lock holds that trait at the current snapshot during rolls and mixing. A Head parts or Other parts lock also holds the body and rig, so attachment hosts and sockets stay valid; a Body-only roll is disabled while either is on. The Body lock does not freeze appendages.

## Saved discoveries

**Save discovery** copies the current blueprint and its recipe into the collection. Exact duplicate blueprints are not added twice, and a new save never overwrites an earlier one. Editing a loaded discovery changes only the working copy; save again to keep the new branch.

Each card has **Load**, **Favorite**, **A**, **B** and **Remove**. Removal asks for confirmation and does not affect the current creature or a parent already captured from that card. Search and Favorites only filter the display.

### Storage and backup

- The collection holds up to 48 discoveries. Nothing is evicted automatically: at capacity, back up and remove an entry before adding another.
- The collection is kept in local browser storage. If storage is unavailable, denied or full, the interface says so and keeps the collection in memory for the current page only. A corrupt existing save is not overwritten.
- **Back up collection** downloads `Morph-Lab-discoveries.json`. Thumbnails are regenerated from the blueprints and are not stored in it.
- **Import collection** validates the whole file (8 MB limit) before merging. It keeps current entries, skips exact duplicate blueprints and resolves record-ID collisions. Invalid input, or an import that would exceed capacity, leaves the collection unchanged.

Back up before moving the HTML file, changing browsers, or closing a page whose collection is memory-only.

## Mix

1. Set parents with a card's **A** or **B** button, the parent selector, or **Use current**. Parents are independent copies and do not follow later edits.
2. Move **Blend amount**. The master slider changes every unlocked channel. Open **Separate blend channels** to set body, head attachments, other attachments, surface, colors and motion individually.
3. Select **Keep mix** (one undo step) or **Cancel** (restores the previous creature). **Save discovery** commits a pending preview before saving it.

Every slider position is computed from the same parents and pre-preview snapshot, so changes never accumulate. Randomize and variation controls are disabled until the mix is kept or cancelled. Parents and saved discoveries never change while you slide.

This is recipe mixing, not mesh morphing. Different body graphs, and humanoid versus creature rigs, switch between sources instead of interpolating. Attachments remap through the normal host and socket rules. The 32-gene limit and the compatibility and export checks still apply.

The Advanced workshop has a separate five-channel mixer with graph rules and mutation; see [mixer.md](mixer.md).

## Preview

The preview offers Color, Clay and Wire views, **Fit view**, drag to rotate, wheel to zoom, **Motion phase**, **Play** and **Turntable**. CPU playback is throttled and is not a frame-rate measurement.

The CPU preview shows real geometry but not custom GPU shaders, fine texture detail, shadows or every material effect. It is not proof of GPU appearance or physics behaviour.

## Export and import

| Control | File |
|---|---|
| **Export blueprint** | `<name>.morph.json`: the current editable schema-6 creature |
| **Export roll / mix recipe** | `<name>.discovery.json`: both sources, the frozen lock source, the result, channel settings, operation and seed |
| **Import blueprint or recipe** | Loads a `.morph.json` blueprint or a `.discovery.json` recipe |
| **Back up collection**, **Import collection** | `Morph-Lab-discoveries.json` |
| **Build GLB asset** | Opens the checked asset exporter; see [export.md](export.md) |

An imported discovery recipe is recomputed and checked against its saved result. Renaming a discovery does not invalidate its recipe.

## Limits

- Mixing blends recipes, not arbitrary mesh topology.
- Discoveries are local to the browser. There are no accounts or cloud sync.
- Undo and redo cover the current session only.
- Existing geometry warnings (for example on Abyss angler and Revenant) are not changed by Create; inspect a model before production use. See [inspector.md](inspector.md).
